Goal

When the main monthly income is greater than zero, show fields for an additional income amount and income type. Each field needs a unique ID.

HTML

Place this container where the extra inputs should appear:

<div id="additionalIncomeFields"></div>

Make sure the JavaScript file is loaded near the end of the page:

<script src="budget.js"></script>
</body>
</html>

JavaScript

let incomeNumber = 0;

function additional(incomeAmount) {
  const fields = document.getElementById("additionalIncomeFields");

  if (incomeAmount <= 0) {
    fields.innerHTML = "";
    return;
  }

  if (fields.children.length > 0) {
    return;
  }

  incomeNumber++;

  const amountId = `incomeAmount${incomeNumber}`;
  const typeId = `incomeType${incomeNumber}`;

  fields.innerHTML = `
    <label for="${amountId}">Additional income amount:</label>
    <input type="number" id="${amountId}" name="${amountId}" min="0">

    <label for="${typeId}">Income type:</label>
    <input type="text" id="${typeId}" name="${typeId}" placeholder="Example: Freelance">
  `;
}

const incomeInput = document.getElementById("income");

incomeInput.addEventListener("input", () => {
  additional(Number(incomeInput.value));
});

Line-by-line notes

let incomeNumber = 0; keeps count of the generated income fields so their IDs can be unique.

function additional(incomeAmount) defines a function that receives the value typed into the main income field.

document.getElementById("additionalIncomeFields") finds the HTML container where the extra inputs will be displayed.

if (incomeAmount <= 0) checks whether the main income is zero, negative, or blank. fields.innerHTML = "" clears the extra inputs, and return ends the function immediately.

if (fields.children.length > 0) checks whether the extra inputs already exist. The return avoids creating duplicate fields every time a user types another character.

incomeNumber++; adds one to the counter. The first generated group uses 1.

The template strings `incomeAmount${incomeNumber}` and `incomeType${incomeNumber}` make IDs such as incomeAmount1 and incomeType1.

fields.innerHTML = `...` inserts the labels and inputs into the container. Backticks allow multiple lines and ${...} inserts variables into the HTML.

const incomeInput = document.getElementById("income") finds the original input with id="income".

addEventListener("input", ...) runs whenever the user types, deletes, or pastes in that input. Number(incomeInput.value) converts the input's text value into a number before passing it to additional.
